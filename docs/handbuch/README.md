# Handbuch

Bedienungsanleitung für Nutzerinnen und Nutzer. Das Support-Team beantwortet
Fragen zur Bedienung aus diesen Seiten; Änderungen an der Bedienung werden im
selben Pull Request hier nachgezogen.

Aufbau: eine Datei je Aufgabe aus Sicht der Nutzenden (z. B. `anmelden.md`,
`antrag-anlegen.md`), jeweils mit nummerierten Schritten, so wie sie auf dem
Bildschirm erscheinen (Beschriftungen von Schaltflächen und Feldern wörtlich).
